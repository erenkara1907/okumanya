## Contribution Guidelines

When contributing to this project, please:

1. **Follow Semantic Versioning**: Use appropriate version numbers for your changes
2. **Update Changelog**: Add your changes to the [Unreleased] section
3. **Write Tests**: Include tests for new features and bug fixes
4. **Document Changes**: Update documentation for significant changes
5. **Code Quality**: Ensure your code passes all quality checks

### Change Categories

- **Added**: New features and functionality
- **Changed**: Changes in existing functionality  
- **Deprecated**: Soon-to-be removed features
- **Removed**: Removed features
- **Fixed**: Bug fixes
- **Security**: Security-related improvements and fixes

### Version Guidelines

- **MAJOR**: Incompatible API changes (1.0.0 → 2.0.0)
- **MINOR**: New functionality in backward-compatible manner (1.0.0 → 1.1.0)  
- **PATCH**: Backward-compatible bug fixes (1.0.0 → 1.0.1)
